# KeenKeeper

A personal relationship management app to help you stay intentionally connected with the people who matter most in your life.

---

## 📖 Description

KeenKeeper is your personal shelf of meaningful connections. It helps you track when you last reached out to friends, log interactions like calls, texts, and video chats, and make sure no important relationship slips through the cracks.

---

## 🛠️ Technologies Used

- **Next.js 15** — App Router, dynamic routing, server components
- **HeroUI** — Component library for UI elements
- **Tailwind CSS** — Utility-first styling
- **React Icons** — Icon library
- **LocalStorage** — Client-side interaction history
- **React Toastify** — Toast notifications

---

## ✨ Key Features

### 1. 👥 Friend Dashboard
View all your friends — with their contact status (On-Track, Almost Due, Overdue), tags, and days since last contact.

### 2. 📋 Friend Details Page
Click any friend card to open a detailed profile — see their relationship goal, quick check-in options (Call, Text, Video), and key stats like days since contact and next due date.

### 3. 📅 Interaction Timeline
Every call, text, and video interaction is logged and displayed on a filterable Timeline page — so you always know your recent history with each friend.
